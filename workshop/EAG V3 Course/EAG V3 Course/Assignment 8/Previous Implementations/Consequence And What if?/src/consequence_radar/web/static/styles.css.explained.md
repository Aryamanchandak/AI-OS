# `web/static/styles.css`

Hand-written, unminified single stylesheet for the whole UI (editorial/newsletter look: `DM Sans` body font, `Instrument Serif` display font pulled from Google Fonts, warm paper/moss/amber palette defined as CSS custom properties on `body`). Line 1 holds the bulk of the rules (layout for the masthead, hero, submit form, run history list, run-progress panel, failure panel, newsletter article view, candidate/graph/ledger cards, and the audit-artifact `<pre>` blocks); line 2 is a single `@media(max-width:800px)`/`@media(max-width:420px)` responsive block; line 3–5 are three small rules for `.field-help`/`.form-status`, added after the fact for the form's client/server validation messaging (`.form-status.is-error` in red, matching the error state `app.js` and `index.html` toggle). It is served at `/static/styles.css` and linked identically from both `index.html` and `run.html`, so every class it defines is shared across the two templates — there is no page-specific stylesheet.
