## Metadata
- Author: [[Kwame Anthony Appiah]]
- Full Title: The Age of De-Skilling
- Category: #articles
- Summary: AI changes what skills we need by shifting work from doing to supervising and judging.  
This can dull some basic abilities but also creates new skills like prompting and oversight.  
The key is keeping core human judgment so we stay authors, not servants, of our tools.
