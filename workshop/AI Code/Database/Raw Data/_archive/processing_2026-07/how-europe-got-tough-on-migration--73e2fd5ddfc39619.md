## Metadata
- Author: [[Emma Bubola & Jeanna Smialek]]
- Full Title: How Europe Got Tough on Migration
- Category: #articles
- Summary: Europe has become tougher on migration, with many countries joining to limit asylum and deport more undocumented migrants. Leaders from both right and left now support stricter border controls and sending asylum seekers to third countries. This shift reflects growing public concern about migration and has changed how Europe handles refugees and immigrants.
