A composite is a group of individual discretionary portfolios with similar investment strategies, objectives, and mandates. 



Security index (S&P 500) is a collection of securities weighted on market capitalisation, while composite (dow tech composite) is a collection of securities that have similar characteristics, and mandates and strategies and business. 



A composite must include all fee-paying, discretionary policies (current and past) that the firm has managed in line with the composites strategy. 



While creating composite firms must first establish which portfolio goes where, before calculating the performance of each portfolio and therefore the composite. This is to prevent, firms from artificially inflating the performance of the composites. All portfolio should be in only one , and only one portfolio.
