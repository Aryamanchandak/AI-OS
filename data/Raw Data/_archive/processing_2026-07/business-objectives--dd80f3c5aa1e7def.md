We want to create a suite of agents for small to medium orgnaisations. what I forsee this suite of agents doing is allowing small to medium business ownders with, high turnovers to be able to ask query ‘experts’ in fields to get accruate and situation ready answers. 


most business owners will not have an idea of how to get the most out of these LLM chatbots and agents, let alone trust them. As every business has its own nuance, an answer from a standard LLM chatbot will not help solve answers for this business owner. What we propose is we create a workflow, where the user can type a prompt in a natural langauge, this prompt goes starts a prompting workflow where the LLM asks questions to increase context and build a proper prompt retrieving information between questions to create a fleshed out prompt, that does exactly as the user requires. this prompt is then sent to a routing agent which decides which agent it should engage from a suite of agents and starts the workflow. The agent again access the companies stored confidential data for direction and context on its work. feeding its output but to a formatting agent, which uses information retrived from the internat data sources and the agents retrieved inforamtion to create an output in the preferences and style of the user, and outputs the answer. 

We want to create a multi agent system, where each agent talks and handshakes and hands off tasks to the other agents, ensuring to give the user a comprehnesive answer. 

we also want to create an internal data source for each business, creating a standard or hyper edge based knowledge graph, with a vector db system to store the documents, and use as information for semantic and contextual understanding for the prompts.
