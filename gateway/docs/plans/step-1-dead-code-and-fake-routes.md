# Step 1: Remove Dead Code and Fake Routes

## Why
Some code is loaded but never used. Some routes answer with made-up values, which mislead any agent that trusts them. Removing both makes the gateway smaller without changing anything real.

## Definition of done
- Nothing on the step 1 list remains: `GatewaySettings`/`gateway.yaml`, `RouterDecision`, the meter's `Usage`, the stale docstring, `/routers`, `/telemetry`, and the fake fields in `/embedders`, `/status` and `/providers`.
- The full test suite passes, and you've seen the output.
- `contracts/openapi.json` (the saved description of every route) is regenerated, and the staleness test passes.

## Decisions already made
- These items are truly not needed (agreed in `docs/yagni-review-followup.md`).
- Items worth finishing are kept, not deleted, and are reworked in later steps: the ledger, the typed response models and `load_mapping`.

## Open questions
- None.

## Tests first
Add these to `tests/test_llm_contract.py`, using the client setup that file already has:
- `GET /api/llm/routers` and `GET /api/llm/telemetry` return 404 ("not found").
- `/api/llm/embedders` no longer contains `fixed_dim`, `max_input_chars`, `backoff_steps_s` or `live`.
- `/api/llm/status` no longer contains `live` or `limits`.
- `/api/llm/providers` no longer contains `shortcuts` or `limits`.

Run them first. They should **fail**, which proves they test something real.

## Verification
1. Record the starting point: `.venv/bin/pytest -q`. If anything already fails, stop and report it.
2. Add the new tests. Run `.venv/bin/pytest -q tests/test_llm_contract.py`. The new tests should fail.
3. Make the changes. Then run `.venv/bin/python scripts/export_openapi.py` to regenerate the contract file.
4. Run `.venv/bin/pytest -q`. Everything should pass. Show you the full output.
5. Run `grep -rn "GatewaySettings\|RouterDecision\|gateway\.yaml\|/routers" src tests config`. Expect no matches.
